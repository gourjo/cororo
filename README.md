# Cororo

Экспериментальная песочница об эволюции жизни: игрок начинает с простого организма,
адаптирует его к процедурному миру и постепенно открывает разум, культуру и архитектуру.

Сейчас в репозитории находится **нулевой вертикальный срез**: автономная браузерная
симуляция процедурного биома, редактор признаков существа и короткий цикл
«собирать пищу → размножаться → мутировать → перейти на следующую стадию».

## Первый запуск

Если это ваш первый опыт программирования, начните с подробной инструкции:
**[«Как запустить Cororo с нуля»](docs/BEGINNER_GUIDE.md)**. В ней объяснено,
какой именно терминал открыть на Windows, macOS или Linux, как найти папку проекта
и что должно появиться после каждой команды.

Краткий вариант для тех, кто уже умеет пользоваться терминалом:

Проект не требует сборки или сторонних зависимостей:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Управление: `WASD`/стрелки — движение,
`Space` — рывок, мышь — выбор точки назначения. Параметры существа можно менять
в редакторе справа; новый мир воспроизводится по seed.

Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl+C`.

## Технологическое решение

Браузерная версия — быстрый проверяемый прототип, а не финальный технологический
стек. Для production-версии выбран **Godot 4 + GDScript/C#**: он лучше соответствует
небольшой команде, data-driven симуляции и инструментам пользовательского творчества.
Детали, критерии и условия пересмотра решения описаны в
[ENGINE_SELECTION.md](docs/ENGINE_SELECTION.md).
