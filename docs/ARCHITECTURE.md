# Архитектура

## Принципы

1. **Данные важнее сцен.** Геном, виды, биомы, культуры и строительные наборы —
   версионированные ресурсы, а не логика внутри визуальных узлов.
2. **Фиксированный шаг симуляции.** Рендер интерполирует состояние и не определяет результат.
3. **Детерминизм по seed.** Каждый генератор получает собственный поток случайности.
4. **Уровни детализации.** Рядом с камерой живут агенты; вдали — агрегаты популяций.
5. **Один формат для игрока и генератора.** Ручной редактор создаёт те же blueprint,
   которые производит процедурный pipeline.

## Целевая схема Godot

```text
Presentation (Scenes/UI/Audio)
           ↓ commands / ↑ snapshots
Application (game loop, tools, saves, progression)
           ↓
Simulation Core (world, ecology, agents, genetics, society)
           ↓
Content Model (Genome, Species, Biome, Culture, BuildingBlueprint)
           ↓
Infrastructure (seed streams, chunks, persistence, mod loading, telemetry)
```

`Simulation Core` не зависит от Node API и времени кадра. Это позволяет запускать
headless-тесты, ускорять время и позднее вынести тяжёлые системы в C# или GDExtension.

## Мир

- Мир делится на чанки с координатным seed: `hash(world_seed, x, y, generator_version)`.
- Terrain генерируется шумами, поверх него отдельными проходами — климат, ресурсы и биомы.
- Активное кольцо содержит полных агентов; дальние чанки хранят численность, генофонд,
  запасы и события и обновляются редкими крупными шагами.
- Изменения игрока записываются как sparse-delta поверх воспроизводимой основы.

## Сущность и геном

Композиция предпочтительнее глубокой иерархии. Агент имеет компоненты `Transform`,
`Metabolism`, `Genome`, `Sensors`, `Motor`, `Brain`, `SocialMemory`. Геном разделён на:

- морфологию (граф частей тела и соединений);
- параметры (размер, скорость, эффективность, радиусы чувств);
- контроллер поведения;
- косметический слой.

Мутации — операции над blueprint с ограничениями валидатора. Фенотип вычисляется из
генотипа и среды, поэтому один геном может проявляться по-разному.

## Общество, культура и архитектура

После появления разума агенты формируют отношения и передают мемы: знания, нормы,
предпочтения и символы. Культура — распределение мемов в группе, а не единый enum.
Здания описываются графом функциональных пространств и набором модулей; визуальная
геометрия выводится из графа, доступных материалов, тела строителя и культурных мотивов.

## Процедурная музыка

Музыкальный движок получает высокоуровневое состояние (биом, риск, плотность жизни,
культурные мотивы), а не игровые объекты. Сначала используются заранее созданные
стемы и правила гармонии; генерация нот/тембров добавляется только после проверки
переходов. Пользовательский редактор музыки сознательно отложен.

## Сохранения и моды

Сохранение содержит версию схемы, seeds, дельты чанков, состояние важных агентов и
пользовательские blueprint. Миграции обязательны с первого публичного формата.
Моды загружают декларативный контент; исполняемый код выключен по умолчанию.

## Прототип в этом репозитории

Браузерный срез сохраняет границу между чистой моделью (`src/simulation.mjs`),
приложением (`src/app.mjs`) и WebGL 2-представлением (`src/renderer3d.mjs`). Рендерер
содержит минимальный shader/mesh pipeline, перспективную камеру и процедурную сборку
фенотипа; он не влияет на результаты симуляции. Seeded RNG, генерация мира и изменение
генома доступны для headless-тестов. Этот код — reference prototype: в Godot переносится
модель, визуальный язык и наблюдения плейтестов, а не сам WebGL-рендерер.
