# Как запустить Cororo с нуля

Эта инструкция рассчитана на человека, который раньше не пользовался терминалом.
Ничего программировать для первого запуска не нужно. Вы запустите маленький локальный
веб-сервер, а затем откроете игру в обычном браузере.

## Что такое терминал

Терминал — это программа, в которую вводят текстовые команды. Нужен **один** из вариантов:

| Ваша система | Что открыть |
|---|---|
| Windows | **PowerShell**: нажмите `Win`, напишите `PowerShell`, нажмите Enter |
| macOS | **Terminal**: откройте Spotlight (`Cmd+Space`), напишите `Terminal`, нажмите Enter |
| Linux | **Terminal**: обычно открывается сочетанием `Ctrl+Alt+T` |
| VS Code | Меню **Terminal → New Terminal**; панель появится снизу |
| GitHub Codespaces | Меню **Terminal → New Terminal** прямо в открытом Codespace |

Не вводите команды в адресную строку браузера. Серые блоки ниже — команды для терминала.
Вводите по одной строке и после каждой нажимайте Enter.

> **Важно:** путь `/workspace/cororo` существует только в облачном рабочем окружении,
> где разрабатывался проект. На вашем Windows-компьютере такого пути нет — это и означает
> красная ошибка «путь не существует». Сначала проект нужно скачать на компьютер.
>
> Надписи `bash`, `powershell` и тройные обратные кавычки вокруг примеров — это оформление
> документа, а не часть команды. Например, нужно ввести только `py --version`, но не
> вводить слово `powershell`, слово `bash` или символы обратных кавычек из рамки примера.

## Сначала скачайте проект на Windows

### Способ 1: ZIP-архив — рекомендуется новичку

1. Откройте в браузере страницу репозитория Cororo на GitHub.
2. Нажмите зелёную кнопку **Code**.
3. Выберите **Download ZIP**.
4. Дождитесь загрузки и откройте папку **Загрузки** (`Downloads`).
5. Нажмите на ZIP-файл правой кнопкой мыши и выберите **Извлечь всё…**.
6. В окне распаковки можно оставить предложенную папку и нажать **Извлечь**.
7. Откройте распакованную папку. В ней должны находиться файл `index.html` и папки
   `src`, `docs`, `tests`. Иногда GitHub создаёт дополнительную внешнюю папку — найдите
   внутри неё именно ту, где лежит `index.html`.

Теперь откройте PowerShell сразу в правильной папке:

1. В Проводнике Windows откройте папку, где виден `index.html`.
2. Кликните по адресной строке Проводника — там, где показан путь к папке.
3. Напишите `powershell` и нажмите Enter.
4. Откроется PowerShell. Его строка должна выглядеть примерно так:

```text
PS C:\Users\TEST\Downloads\cororo-main>
```

После этого **не нужно вводить `cd /workspace/cororo`**: PowerShell уже находится в
папке проекта. Перейдите сразу к разделу «Проверьте наличие Python» ниже.

### Способ 2: через Git — только если Git уже установлен

На странице GitHub нажмите **Code → HTTPS** и скопируйте адрес репозитория. Затем в
PowerShell перейдите в папку, куда хотите скачать проект, например:

```powershell
cd C:\Users\TEST\Downloads
```

Введите `git clone`, пробел и вставьте скопированный адрес. Пример формы команды:

```powershell
git clone АДРЕС_РЕПОЗИТОРИЯ
```

`АДРЕС_РЕПОЗИТОРИЯ` нужно заменить настоящим адресом, не вводить буквально. После
загрузки выполните `cd` с именем созданной папки, например `cd cororo`. Если команда
`git` не найдена, используйте ZIP-способ — устанавливать Git ради первого запуска не нужно.

## Вариант A: проект уже открыт в VS Code или Codespaces

Это самый простой случай.

### Шаг 1. Откройте терминал

В верхнем меню VS Code выберите **Terminal → New Terminal**. Внизу появится строка,
рядом с которой обычно написано `$`, `>` или путь к папке.

### Шаг 2. Убедитесь, что открыта папка Cororo

Введите:

```bash
pwd
```

Только в Codespaces/облачном рабочем окружении путь может выглядеть так:

```text
/workspace/cororo
```

На вашем Windows-компьютере путь будет выглядеть как `C:\Users\ВашеИмя\Downloads\cororo-main`.
Главное, чтобы это была папка с файлом `index.html`. Если это не так, введите `cd`, пробел и путь к проекту:

```powershell
cd "C:\Users\ВашеИмя\Downloads\cororo-main"
```

Для Windows пример может выглядеть так:

```powershell
cd C:\Users\ВашеИмя\Downloads\cororo
```

Не копируйте пример вслепую: замените путь на реальное расположение вашей папки.
В VS Code реальный путь можно увидеть через **File → Open Folder**.

### Шаг 3. Проверьте наличие Python

Сначала попробуйте:

```bash
python3 --version
```

Если появилась строка вроде `Python 3.12.1`, всё готово. Если написано, что команда
не найдена, на Windows попробуйте:

```powershell
py --version
```

Если сработал только `py`, во всех дальнейших командах заменяйте `python3` на `py`.
Если не работает ни одна команда, установите Python 3 с официального сайта Python.
На Windows во время установки включите флажок **Add Python to PATH**, затем закройте
и заново откройте терминал.

### Шаг 4. Запустите проект

На macOS, Linux, Codespaces и обычно в VS Code:

```bash
python3 -m http.server 8000
```

На Windows, если на предыдущем шаге сработала команда `py`:

```powershell
py -m http.server 8000
```

Команда не должна сразу завершиться. Вы увидите сообщение примерно такого вида:

```text
Serving HTTP on 0.0.0.0 port 8000 ...
```

Терминал после этого выглядит «занятым» — это нормально: сервер работает. Не закрывайте
это окно, пока игра запущена.

### Шаг 5. Откройте игру

Откройте Chrome, Firefox, Edge или Safari и введите в **адресную строку**:

```text
http://localhost:8000
```

В Codespaces редактор может показать уведомление об открытом порте `8000`. Нажмите
**Open in Browser**. Если уведомления нет, откройте вкладку **Ports**, найдите порт
`8000` и нажмите значок браузера.

Если всё получилось, появится зелёный экран **CORORO** с существом, показателями
энергии и редактором генома.

### Шаг 6. Остановите проект

Вернитесь в тот терминал, где работает сервер, и нажмите:

```text
Ctrl+C
```

Это сочетание не нужно печатать: удерживайте `Ctrl` и нажмите клавишу `C`.

## Если проект находится в ZIP-архиве

Не запускайте проект прямо из ZIP. Выполните подробные действия из раздела
«Сначала скачайте проект на Windows», затем при желании в VS Code выберите
**File → Open Folder** и откройте распакованную папку.

Можно запустить проект и без VS Code: откройте системный терминал и командой `cd`
перейдите в распакованную папку. Но для первого раза VS Code обычно понятнее.

## Как играть

1. Передвигайте светящееся существо клавишами `W`, `A`, `S`, `D` или стрелками.
2. Также можно кликнуть мышью в нужное место мира.
3. Собирайте маленькие светло-зелёные точки — они восстанавливают энергию.
4. Избегайте красноватых областей: они отнимают энергию.
5. При высокой энергии автоматически появляется потомок.
6. Измените ползунки **Скорость**, **Чутьё**, **Панцирь** и нажмите
   **Применить мутацию**. Мутация стоит 25 единиц энергии.
7. В поле **Новый мир** можно написать любое слово и нажать `↻`. Одинаковое слово
   создаёт одинаковую стартовую карту.

`Space` даёт рывок, но ускоряет расход энергии. Кнопка `Ⅱ` сверху ставит симуляцию
на паузу.

## Если не работает

### Браузер пишет «Не удаётся получить доступ к сайту»

- Проверьте, что терминал с сервером всё ещё открыт.
- Проверьте адрес: нужен именно `http://localhost:8000`, не `https`.
- Посмотрите, нет ли в терминале красного сообщения об ошибке.

### Терминал сообщает, что порт уже занят

Кто-то уже использует порт `8000`. Запустите сервер на другом порту:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

### Открывается список файлов, а не игра

Сервер запущен не из папки проекта. Нажмите `Ctrl+C`, перейдите в папку `cororo`
командой `cd` и снова запустите сервер. В правильной папке находятся `index.html`,
`styles.css`, `src` и `docs`.

### Игра открылась, но экран выглядит неправильно

Обновите страницу сочетанием `Ctrl+R` (`Cmd+R` на macOS). Затем откройте инструменты
разработчика клавишей `F12`, перейдите на вкладку **Console** и сохраните текст красной
ошибки — он пригодится для диагностики.

## Как проверить, что код работает

Эта проверка необязательна для игры. Она полезна перед изменением исходников.
Нужен установленный Node.js. В новом терминале, находясь в папке `cororo`, выполните:

```bash
node --test tests/*.test.mjs
```

Успешный результат содержит `pass 6` и `fail 0`. Если команда `node` не найдена,
можно пока пропустить этот шаг: для запуска самой игры Node.js не требуется.

## Что изменять первым

Для самого первого эксперимента откройте `src/simulation.mjs` в VS Code:

- число `34` определяет начальное количество еды;
- число `11` определяет количество опасных областей;
- значение `72` — стартовая энергия существа;
- значение `25` — цена мутации.

Меняйте только одно значение за раз, сохраняйте файл (`Ctrl+S`) и обновляйте страницу.
Если что-то сломалось, отмените последнее изменение сочетанием `Ctrl+Z`.

Следующий серьёзный этап — не дописывать всю игру в браузере, а создать отдельный
Godot 4 spike по плану проекта. Текущая версия нужна для обучения и проверки игрового
цикла, поэтому её нормально изменять, ломать и переделывать.
